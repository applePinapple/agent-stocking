# 策略1

小火箭信号与筹码获利比例策略。

## 1. 基本设置

每次使用本策略时，必须单独指定以下两个参数，并在回测说明及结果报告中明确输出：

- **回测标的**：股票名称及证券代码。
- **回测区间**：明确的开始日期及结束日期，并注明实际数据截止日期。

这两个参数不设固定值，不沿用此前使用的标的或区间；未提供时，应先明确后再执行回测。

| 项目 | 规则 |
| --- | --- |
| 判断周期 | 日线 |
| 初始资金 | 人民币1,000,000元 |
| 单次买入额度 | 每次小火箭最多投入100,000元，包含买入成交金额及该笔买入的全部费用 |
| 加仓规则 | 已有持仓时，新出现的小火箭仍可触发一笔新的买入 |
| 正常成交方式 | 理想收盘价执行 |
| 数据来源 | 本地通达信软件截图 |
| 期末持仓 | 按期末收盘价估值，不强制平仓 |

## 2. 指标与数据口径

### 小火箭信号

以本地通达信日线副图显示的小火箭为信号，出现火箭的交易日记为 **T日**。

小火箭指标代码已加密，无法查看公式。其已知特性为：

- 后续价格跌破某个位置时，已经出现的历史火箭可能消失。
- 原先没有火箭的历史日期，不会在后续行情中突然补出火箭。

目前可提供的信号资料只有现在能看到的历史图，未保存当时的截图或信号记录。因此，当前截图不能找回已消失的火箭，也不能用于证明某日当时从未出现过火箭。

### 筹码获利比例

使用本地通达信软件筹码区域显示的获利比例，按对应交易日收盘时的数值判断。

该数值不等同于本笔持仓或账户的投资收益率。行情价格、小火箭、筹码获利比例及封板状态均以本地通达信截图为依据。

## 3. 买入观察窗口

每次小火箭对应一个包含 **4根实际日K线** 的观察窗口：

**T日、T＋1日、T＋2日、T＋3日。**

停牌期间没有K线，不占用观察窗口的根数。

4根K线用于判断买入条件的首次触发；因封板而已经进入顺延的买入，继续按第5节处理。

## 4. 买入条件与金额

在该次小火箭的观察窗口内，逐日检查收盘筹码获利比例。

当其**首次严格大于45%**时，触发该次小火箭对应的买入：

1. 正常情况下，按触发日收盘价买入。
2. 单次总支出不超过100,000元，包含该笔买入的全部费用。
3. 按实际成交价格、费用及适用的申报数量规则，向下换算可买入股数。
4. 每次小火箭只使用一次买入额度，不因同一窗口内再次满足条件而重复买入。
5. 已有持仓时，新的小火箭仍可按相同条件新增一笔买入。

获利比例恰好等于45%时，不触发买入。

尚未买入时，若收盘筹码获利比例**严格低于40%**，则取消该次未完成的买入机会。该条件同样适用于已经触发但仍在顺延、尚未成交的买入。

窗口内始终没有触发买入条件的，该次小火箭买入资格到期失效。

## 5. 涨停顺延与取消

“涨停”按**收盘封板**判断。

若买入触发日收盘封板，则不按该日收盘价买入，将该次买入顺延至**下一交易日开盘**尝试执行。

- 下一交易日开盘仍无法成交，则继续顺延至后续交易日开盘。
- 顺延买入按实际开盘价重新换算股数，含费用的总支出仍不得超过100,000元。
- 连续一字涨停板的统计从**买入触发日**开始，包含触发当天；买入触发日可能晚于小火箭出现日。
- 若连续3个实际交易日均为一字涨停板，取消该次尚未成交的买入。
- 顺延期间若先触发买入前获利比例低于40%的取消条件，则取消该次买入。

## 6. 卖出条件

持仓期间，逐日检查收盘筹码获利比例。卖出监控不受4根买入观察窗口的限制。

当收盘筹码获利比例**严格低于40%**时，按该日理想收盘价清仓，但仅卖出当日可卖出的持仓：

- 当天买入或加仓的股份，当天不卖出。
- 以前交易日买入的旧仓，仍按卖出条件卖出，不因当天新增买入而停止卖出。
- 若全部持仓均为当天新买入的股份，则当天不卖出。

获利比例恰好等于40%时，不触发卖出。

## 7. 费用与期末收益

所有买卖费用均计入资金变化与最终收益。每次买入的100,000元额度包含该笔买入费用，卖出费用在实际卖出时扣除。

期末未平仓股份按期末收盘价估值，不补造卖出交易，不预扣尚未发生的卖出费用。

- **期末总资产 = 期末现金余额＋期末持股数量×期末收盘价。**
- **总收益率 = 期末总资产÷1,000,000－1。**

具体费用参数、可用现金不足一笔买入额度时的处理、重叠火箭信号的归属，以及无法卖出或当日新增股份未卖出后的指令处理，尚未指定，实施回测时不得自行补定。

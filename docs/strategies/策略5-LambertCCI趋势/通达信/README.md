## 使用步骤

1. 参考[本机快捷键记录](../../../tongdaxin-shortcuts.md)。行情界面按`Ctrl+F`，在**专家系统公式**中选择新建或需使用的公式，把`专家系统公式.txt`原文复制到正文。
2. 在公式编辑器参数表添加`SID`，最小3、最大21；评测运行值必须为 **5**。原通用模板默认3，其他策略需手动改为本策略号。专用源码也不能漏配SID。
3. 点击**测试公式**，通过后保存。原源码中可能保留编写时的`PENDING`等注释，为匹配实际运行哈希未修改；当前状态以上述运行证据为准。
4. 返回行情报价/自选股界面，按`Ctrl+S`进入**程序交易评测系统**，先选择本目录原始正文对应的专家系统公式和**日线**；将评测运行参数SID设为 **5**。
5. 点击**引入方案**，选择本目录的`策略5-程序交易评测方案.tes`。引入后仍须确认公式正文及参数正确，并按下表核对日期、7只股票、前复权、资金、开平仓价位、费用、一字板延后和期末处理，不能依靠方案名称判断所选策略。
6. 查看设置报告，核对全部设置后再运行并保存结果。最终买卖信号不再额外`REF(...,1)`，成交价位由评测设置选择。

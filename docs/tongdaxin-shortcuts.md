# 通达信快捷键学习与速查

查阅日期：2026-10-23；历史加载与 F1 报表说明补充于2026-10-24。适用对象：Windows 通达信金融终端的行情、分析和公式界面。

已查阅官方快捷键表、帮助说明和版本更新记录。本文按项目的看盘、公式核对与回测用途整理，完整索引见[官方快捷键与使用 FAQ](https://www.tdx.com.cn/products/helpfile/tdxjysm/)。券商定制版、权限和当前界面会影响实际功能，尚未在你的客户端逐项实测；已完成的本机核对单独记在第8节。

## 输入方式

- `Ctrl+F` 表示按住 Ctrl 再按 F；`F5` 是功能键。
- `06`、`96`、`.933` 是键盘精灵命令串，不是同时按下的按键；保留前导零及英文句点。输入后检查候选条目的名称再确认。
- 操作前确认当前窗口与焦点。公式编辑框中的按键可能用于编辑，不能直接套用行情窗口的含义。
- 操作记录写成“当前界面 → 按键或命令 → 预期界面”，便于发现版本差异。

单独左右键用于移动日期指针，`Shift+左右键` 用于平移图形，两者不可混用。恢复采集时，用左键点击K线区以外的价格轴可恢复图表键盘操作，再将鼠标停在那里，避免图中悬停位置把指针带回其他日期。仅用中键停车不能保证焦点；后台资料或新闻页可能仍保留焦点，盲发`←`会没有效果。

逐日指针移动必须核对弹窗“时间”和筹码“成本日期”，两者应对应目标日，不能只依据UIA的`focused_element`。本机曾出现该字段仍显示后台新闻元素，但图表已经响应键盘的情况；批量移动前先单步核对日期变化。以上为本机焦点实测，见第8节。

复权操作会改变图表价格口径。核对策略时记录图表实际显示的状态；本项目当前的现金成交回测要求使用已确认的不复权数据。显示口径的切换不能替代公司行动核算。

## 5. 容易混淆的版本与界面差异

### F8 随界面变化

- K 线分析图：切换周期，见[官方快捷键表](https://www.tdx.com.cn/products/helpfile/tdxjysm/)。
- 行情报价界面：V7.65 增加了打开行情小窗的 F8 入口，见[V7.65 官方更新说明](https://www.tdx.com.cn/article/soft_7_65.html)。
- 强弱分析等界面：V7.66 支持 F8 刷新，见[V7.66 官方更新说明](https://www.tdx.com.cn/article/soft_7_66.html)。

后续操作脚本应绑定当前界面与预期结果，不把 F8 固定解释成一个功能。

### 自动换页曾改键

V7.65 将自动换页由减号改为 `40`。旧表上的 `-` 不能直接套用，依据：[V7.65 官方更新说明](https://www.tdx.com.cn/article/soft_7_65.html)。

### F9、Ctrl+X 与 Ctrl+S

官方[历史快捷键 PDF](https://zxfile.tdx.com.cn/zx/201612/3185123/3185123_fj.pdf)将 `F9` 列为消息中心，当前[官方 FAQ](https://www.tdx.com.cn/products/helpfile/tdxjysm/)的提醒设置说明也引用消息中心 F9；[V7.65](https://www.tdx.com.cn/article/soft_7_65.html)又注明调整了部分品种的 F9 功能。本机映射仍待核对，不能从其他版本表格推定它一定用于委托。

`Ctrl+X` 在当前通用表中指多周期同列；官方 Level-2 常见问题又用它切换五档／十档布局，说明它也有界面差异。依据：[Level-2 官方常见问题](https://help.tdx.com.cn/question.html)。

`Ctrl+S` 在行情功能表中用于评测。编辑框内是否用于保存，需看该窗口菜单，不能直接套用行情映射。

### Ctrl+Enter 受十字线状态影响

K 线分析图中有十字线时打开历史分时与分笔；分析图或分时图无十字线时返回行情列表位置。依据：[官方图表快捷操作说明](https://www.tdx.com.cn/products/helpfile/tdxjysm/)。

### 未核实的命令保持待确认

`.001`、`001` 及 `.101`—`.116` 的逐项功能未在本次查阅的官方资料中核实，暂不作为本地操作依据。需要时查实际客户端菜单，不按记忆补写。

`F12` 是官方列出的交易委托入口。官方资料另列买入、卖出、撤单及闪电交易热键，部分依赖交易权限；完整映射见[官方交易热键表](https://www.tdx.com.cn/products/helpfile/tdxjysm/)。这些属于账户交易功能，应与本项目的历史评测操作区分。

## 7. 本项目后续使用顺序

1. 记录客户端名称、版本、图表周期与复权状态。
2. 从盘后下载入口准备指定区间的历史行情，核对完整性。
3. 打开公式管理，按用户原文录入策略，记录参数、版本和未明确条件。
4. 在 K 线上加载指标或专家系统指示，对照应触发与不应触发的历史日期。
5. 进入评测界面，明确资金、成交时点、费用、仓位、证券范围和区间，检查是否符合策略要求。
6. 保存评测输出与成交明细；和本地框架比较时逐项对齐口径，解释差异后再报告收益。

这是根据本项目需要编排的操作顺序。快捷键只负责打开功能，策略和回测参数仍以用户确认的规则为准。

官方帮助确认支持导出当前屏幕的数据，但本次未核实跨版本通用的导出快捷键。实际使用菜单中的“数据导出／导出文件”，核对范围、字段、单位和复权状态。依据：[官方功能演示](https://help.tdx.com.cn/function.html)。

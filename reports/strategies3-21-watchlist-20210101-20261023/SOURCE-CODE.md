# 策略3—21批次源码

这个目录是 `reports/` 默认忽略规则的**源码特例**。仓库只保留经审阅的批次根目录 Python 程序、`CHECKALL` 指标与 `per-strategy` 公式文本，以及本说明。原始行情、原生导出、截图、公告PDF、JSON清单、生成报告及临时文件留在本机。

这些程序依赖本批次的证券范围、目录结构和证据清单，尚未改造成独立通用工具。保留原路径是为了兼容现有来源绑定和本机操作；仅克隆代码不足以重建本批次回测。不要为空缺证据补假数据或绕过 `pending` 检查。可独立运行的合成演示和项目测试见仓库根 README。

| 源码 | 用途 |
| --- | --- |
| `native_execution_permissions.py` | 校验明确的成交许可或原生模拟成交证据，严格检查日期、方向、数量、价格和来源 |
| `scale_in_native_preflight.py`、`scale_in_native_runner.py` | 将本机高精度输入接入策略11/13的分批状态机，分别提供预检和受配置约束的补充回放 |
| `portfolio_native_runner.py` | 将股票、基准、日历与历史股本输入接入策略14/20共享资金引擎；输出明确区分于原生导出 |
| `prepare_*.py` | 准备日历、核验输入、生成分策略公式及不同公式适配版本 |
| `audit_*.py`、`verify_*.py`、`review_*.py` | 审核原生表格、逐笔信号、价格精度、来源及公开报告一致性 |
| `build_*.py`、`merge_native_per_security_ledgers.py` | 根据本地证据组装草稿、报告与分股流水，不补造缺失交易 |
| `validate_*.py`、`test_*.py` | 批次适配器及证据门控测试；部分依赖本机原始输入，区别于根目录的独立单元测试 |
| `native-evaluation/CHECKALL*.txt` | 本机导出用指标源码；v2对指定数值放大2^20以保留导出精度 |
| `native-evaluation/per-strategy/*.txt` | 分策略专家公式、诊断公式及保留的适配版本 |

`scale_in_native_runner.py --help` 和 `portfolio_native_runner.py --help` 可查看参数。实际预检还需要本机 `after-download/`、`native-inputs/`、明确配置及相应来源文件；这些输入不随代码提交。部分早期研究脚本直接使用 `C:/new_tdx` 下的只读缓存，使用前须核对本机路径。

公式文件按历史版本原样保存，其名称或注释不构成验证通过声明。尤其策略6的旧完整公式存在本机编译容量问题，拆分v2曾在应用时导致客户端退出；standalone-v3仍需本机编译与运行验证。不要直接把旧版本当作可用公式运行。修改已绑定证据的公式会改变哈希，需建立新的来源记录。

原生评测文件的保存、指标逐值核对、补充执行器测试以及正式策略收益是不同阶段。当前未完成项目仍以各策略文档和本机检查点为准；未确认规则不得输出正式收益。
